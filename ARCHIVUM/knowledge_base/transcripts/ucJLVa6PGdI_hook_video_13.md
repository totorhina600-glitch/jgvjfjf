## Texte complet (resume du tutorial)

Tutorial Premiere Pro sur comment editer des hooks viraux avec le framework CTV (Camera, Typography, Visual effects).

### Le Framework CTV :
- **C = Camera Movement** : Zoom out sur adjustment layer avec Transform effect, bezier curves pour smoother, motion blur a 360
- **T = Typography** : Word-by-word text avec slide-in animation, keyframes sur opacity + position
- **V = Visual Effects** : Flash transitions (black and white X-ray), stutter effects, chromatic look avec desaturation sur les premieres frames

### Steps detailles :
1. Creer un adjustment layer
2. Ajouter Transform effect (Distort > Transform)
3. Keyframe le scale (100% a zoom out)
4. Bezier curves pour smoother le mouvement
5. Max shutter angle a 360 pour motion blur
6. Ajouter du texte word-by-word
7. Keyframe opacity + position pour slide-in
8. Bezier pour smoother l'animation
9. Flash transitions (2 frames black and white)
10. Sound effects : riser + click + reverb

### Concepts cles :
- Desaturated first frames pour un look chromatique subtle
- Les presets peuvent etre sauvegardes pour reutilisation
- Le CTV framework permet de faire des hooks viraux sans trop d'effort
