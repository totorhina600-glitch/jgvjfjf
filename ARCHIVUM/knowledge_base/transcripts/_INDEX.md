## Concepts cles extraits

### Vidéo 1 (pNIYikmYsyw) — THEORIE + PSYCHOLOGIE
- **Interrupt Theory** : interrompre le scroll avec "freeze point"
- **Orienting Response** : reaction involontaire ("wait, what was that?")
- **4 S's of Hook Writing** : Subject, Stakes, Speed, Super clear
- **Triple Hook Method** : Text hook + Visual hook + Spoken hook (alignes!)
- **Hook Formats** : question, tutorial, problem-solution, secret reveal
- **Power Words** : mots/cluster qui amplifient l'attention
- **Curiosity Gap** : espace entre ce qu'on sait et ce qu'on veut savoir
- **Text Hook** : le plus important (les yeux cherchent le texte en premier)
- **Subject Repeater** + Pain Point Reminder / Dream Outcome / State Change

### Vidéo 8 (bcjDAb7BheI) — ALGO YOUTUBE
- **Hook vs Anti-hook** : contexte vs pas de contexte
- **Anti-hook** = plus puissant (force a chercher l'info)
- **Swipe Ratio cible** : 81.1%
- **3 piliers YouTube** : Argent, Reste sur plateforme, Satisfaction
- **Ideation** : Large audience > niche trop etroite

### Vidéo 9 (BMJAU2n7o2A) — HOOKS FR (le plus important pour nous)
- **Hooks avec intention intrigante** : forcer a rester jusqu'a la fin
- **Identification** : creer des situations que tout le monde vit
- **Imager** : mettre une image/video qui illustre ce qu'on dit
- **Reutiliser les bonnes reponses** des commentaires dans les futurs hooks
- **3 styles de hooks** : Intention intrigante + Identification + Illustration

### Vidéo 10 (S9FlxFv9dxg) — 6 POWER WORDS
- **Subject Clarity Word** : I, we, you, proper noun
- **Action Word** : verbe/adverbe decrivant l'action
- **Objective/Endstate Word** : resultat choquant desire
- **Contrast Word** : base state vs nouveau resultat (A to B)
- **Proof Word** : "again" (optionnel, prouve qu'on l'a deja fait)
- **Time Word** : contrainte de temps (optionnel, augmente l'urgence)

### Vidéo 11 (5A6XVQUopYA) — STOP STACK FORMULA
- **Visual hooks** : interrompre le pattern du feed
- **Audio hooks** : snap, pop, beat drop, silence
- **Text hooks** : mot par mot pour ancrer l'attention
- **Foreshadowing** : montrer le resultat au debut
- **Stack** : combiner visual + text + statement pour plus de tension

### Vidéo 14 (_1FOJwqpZk8) — 6 TYPES DE HOOKS (Hindi)
- **Visual Hook** : Motion + Curiosite + Clarity
- **Unbelievable Hook** : quelque chose d'impossible
- **Pain Point Hook** : probleme specifique et niche
- **Curiosity Gap** : information incomplete
- **Relatability Hook** : situation commune
- **Transformation Hook** : Before/After
